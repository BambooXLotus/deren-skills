# ADO writeback comment body

The HTML comment `rick-intel` posts back to the ADO work item after writing the dossier. ADO renders comments as HTML; plain text is unreadable.

```html
<p><em>This was generated by AI during research.</em></p>
<p>
  <strong>Intel file:</strong>
  <code>docs/rick/&lt;AB-id&gt;/intel/current.md</code>
</p>
<ul>
  <li>&lt;N&gt; ACs covered</li>
  <li>&lt;N&gt; findings</li>
  <li>&lt;N&gt; open questions</li>
</ul>
<p>Last gathered: &lt;YYYY-MM-DD&gt;</p>
```

## Idempotency

Fetch existing comments. If one contains the disclaimer `This was generated by AI during research.`, update it via the ADO REST API instead of posting new. If update isn't possible from the CLI, post new and accept the duplicate (warn the user).
